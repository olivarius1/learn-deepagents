

## 子智能体系统

### 任务规划
简单Q-A任务不需要任务规划

稍复杂任务
langGraph 和Qwen-agent区别
- 搜索信息
- 对比分析
- 组织数据
- 撰写报告


### agent 系统可能遇到的问题

- 上下文膨胀

一个研究型子任务多次搜索 write_file/read_file,会积累大量上下文, 而这些过程可能不是最终关心的,我们只需要最终结论或摘要. 通过主-子agent的方式,相当于"扩展"了模型的上下文窗口

- 上下文隔离

子agent 的工具调用,文件读写"默认"不回传给主agent

### 衡量
委派开销大于收益 && 需要/接受上下文隔离
任务拆分后适合多种模型能力
多次搜索和整理的研究型任务,适合并行

### 设计原则
- description 决定主agent何时委派任务及委派给谁
- system prompt 包含输出格式要求和字数限制
- 只给必要的工具
- 选择适合的模型
- 返回结果要精炼 如结论+引用


## 异步子智能体
同步情况下,主agent等待子agent返回
异步: 使用协程,子agent返回task_id, 中途如可以插话/取消. 

子智能体可以通过远程http服务的方式,也可以通过ASGI传输的方式本地部署

ASGI本质上是同一个进程间不同线程通讯的一个标准,借鉴了Starlette框架的ASGI概念

### 主agent对接子agent

使用AsyncSubAgentMiddleware 可以管理使用了标准接口的子agent(不管是本地还是url实现)
